# Nodo Sur Soluciones Digitales — Página empresarial

Empresa ficticia del sector terciario (software a la medida, nube y soporte TI para PyMEs). Proyecto de la Actividad 1 de Desarrollo Full-Stack.

## Archivos
- `index.html`, `styles.css`, `script.js`
- `images/` con `logo.svg`, `hero.svg`, `proyecto-1.svg`, `proyecto-2.svg`, `proyecto-3.svg`

## Ejecutar con Live Server (VS Code)
1. Abrir la carpeta en VS Code.
2. Instalar la extensión Live Server.
3. Clic derecho en `index.html` y elegir "Open with Live Server".

## Publicar en GitHub Pages
1. Crear un repositorio público en GitHub y subir el contenido de esta carpeta (con `index.html` en la raíz).
2. Ir a Settings, luego Pages.
3. En Source elegir la rama `main` y la carpeta `/ (root)`; guardar.
4. Esperar la publicación y abrir la URL.

URL pública: https://alexayalaj.github.io/nodo-sur-fullstack/

Repositorio: https://github.com/alexayalaj/nodo-sur-fullstack

## Capturas para la entrega
1. Vista de escritorio completa (1280 px o más).
2. Vista móvil (F12, Ctrl+Shift+M, iPhone 12 Pro).
3. Validación del formulario mostrando errores.
4. Resultado del validador W3C sin errores (opcional).
5. GitHub Pages activo en Settings, Pages.
